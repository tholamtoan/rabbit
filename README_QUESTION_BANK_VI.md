# Ngân hàng câu hỏi Học cùng Thỏ

Ngân hàng mặc định hiện nằm trong `backend/questionBank.js`. Sau khi triển khai chức năng Admin Upload DOCX, mỗi môn/kỳ thi được cập nhật sẽ lưu vào PostgreSQL/Neon và ghi đè dữ liệu mặc định tương ứng khi website tạo đề.

Xem quy trình sử dụng, cấu hình Render và cơ chế giữ lịch sử chống lặp tại `README_ADMIN_UPLOAD_WORD_VI.md`.
